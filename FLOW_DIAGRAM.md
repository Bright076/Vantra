# System Flow Diagrams

## Signup Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                         USER VISITS /signup                      │
│                     (optionally with ?ref=CODE)                  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                    User Enters Email & Password                  │
│                      Clicks "Sign Up" Button                     │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│              Supabase Auth Creates User Account                  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│               Generate Unique Referral Code (8 chars)            │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│             Create Profile with Welcome Bonus:                   │
│                    • Balance: $2.00                              │
│                    • Points: 20                                  │
│                    • Referral Code: ABCD1234                     │
└────────────────────────────┬────────────────────────────────────┘
                             │
                   ┌─────────┴─────────┐
                   │                   │
         ?ref param present?   ?ref param absent
                   │                   │
                   ▼                   ▼
┌──────────────────────────┐   ┌──────────────────────┐
│  Look up referrer by     │   │   No referral        │
│  referral code           │   │   tracking needed    │
└──────────┬───────────────┘   └──────────┬───────────┘
           │                              │
           ▼                              │
┌──────────────────────────┐             │
│  Set referred_by field   │             │
│  on new profile          │             │
└──────────┬───────────────┘             │
           │                              │
           ▼                              │
┌──────────────────────────┐             │
│  Create referral record: │             │
│  • status: 'pending'     │             │
│  • reward_amount: 1.00   │             │
│  • referrer_id: [UUID]   │             │
│  • referred_id: [UUID]   │             │
└──────────┬───────────────┘             │
           │                              │
           └──────────┬───────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────────┐
│              Redirect to /login with Success Message             │
└─────────────────────────────────────────────────────────────────┘
```

## Referral Payout Flow

```
┌─────────────────────────────────────────────────────────────────┐
│                  User Completes a Task                           │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│              Call processReferralPayout(userId)                  │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│   Check for PENDING referral where referred_id = userId          │
└────────────────────────────┬────────────────────────────────────┘
                             │
                   ┌─────────┴─────────┐
                   │                   │
           Found pending?       Not found?
                   │                   │
                   ▼                   ▼
┌──────────────────────────┐   ┌──────────────────────┐
│  Fetch referrer profile  │   │  Return false        │
│  (current balance/points)│   │  (no action needed)  │
└──────────┬───────────────┘   └──────────────────────┘
           │
           ▼
┌──────────────────────────┐
│  Update referrer:        │
│  • Balance += $1.00      │
│  • Points += 10          │
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│  Update referral record: │
│  • status = 'paid'       │
│  • paid_at = now()       │
└──────────┬───────────────┘
           │
           ▼
┌──────────────────────────┐
│  Return true             │
│  (payout processed)      │
└──────────────────────────┘
```

## Security Flow (Row Level Security)

```
┌─────────────────────────────────────────────────────────────────┐
│                    User Makes Database Request                   │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│                   Supabase Checks RLS Policies                   │
└────────────────────────────┬────────────────────────────────────┘
                             │
                   ┌─────────┴─────────┐
                   │                   │
            profiles table      referrals table
                   │                   │
                   ▼                   ▼
        ┌────────────────────┐  ┌────────────────────┐
        │ Can read own       │  │ Can read own       │
        │ Can update own     │  │ referrals (as      │
        │                    │  │ referrer or        │
        │ Admin can read all │  │ referred)          │
        │ Admin can update   │  │                    │
        │ all                │  │ Admin can read all │
        └────────┬───────────┘  └────────┬───────────┘
                 │                       │
                 └───────────┬───────────┘
                             │
                             ▼
                    ┌──────────────────┐
                    │  Allow or Deny   │
                    │  Request         │
                    └──────────────────┘
```
